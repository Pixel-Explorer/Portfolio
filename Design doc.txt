The board (pinned to "Ui 3d" on Haus of Pixels Studios) clusters around a specific aesthetic called 3D Glassmorphism / Soft Isometric UI. The key examples I catalogued:

3D Glass Financial Charts (SaaSAssetLab) — the anchor pin. Neon green translucent blob-chart rising from a frosted-glass dashboard tile. Real metric labels (+25%, 1.2M) embedded in the 3D surface.
3D Glassmorphism Growth Chart (Behance) — clean bar chart rendered as faceted glass prisms (blue→green gradient), on a white base plane with grid lines.
daily_082 Artem Kazakov — a grid of identical semi-transparent ice-blue cubes with one glowing green focal cube — directly analogous to a heatmap/week-grid.
ByteDance 10th Anniversary — circular platform with layered frosted-glass ring geometry. Depth through transparency stacking.
SETTERS x Kaspersky — green glass cube cluster on a reflective plane. Modularity of repeating glass units.
NAVER design colloquium — green translucent architectural slabs — layered glass bars.
Liquid glass guide (Behance) — teal floating glass dashboard panels arranged in 3D space with connectors — shows node-graph / flow layouts.
Corporate Steel — grey-blue data UI with 3D bar/column charts, pie rings, floating monitor panels.
Microsoft App Store (Behance) — soft green 3D UI elements with subtle inner glow.

Recurring visual grammar across all examples:

MeshPhysicalMaterial territory: transparency 0.3–0.6, roughness ~0.1, metalness 0–0.2, transmission 0.6–0.9 for true glass refraction
Neon accent glow achieved via emissive color on geometry + point lights inside objects
Isometric-ish camera: 45° elevation, ~30° azimuth, orthographic or near-orthographic
Soft ambient light + one directional key + one or two coloured point lights
Base plane = subtle grid or reflective surface
Typography floats as 3D sprites (canvas texture on PlaneGeometry)

Three.js Design Document for Claude Code
# DESIGN DOCUMENT: Anirudh Ledger Archive — 3D Spatial View
# Target: Three.js implementation to replace / augment the flat 2D heatmap
# Visual language reference: 3D Glassmorphism / Soft Isometric UI (as seen in Pinterest board)
# Status of existing 2D view: fully functional; this 3D view is additive / mode-switchable

1. Concept
Replace the "Spatial archive unavailable" placeholder with a 3D glass isometric life-grid — a top-down isometric plane where each filled week-cell becomes a translucent glass prism rising from a base grid. The height of each prism encodes Era (1–10). The colour tint encodes the dominant tag. Hovering a prism reveals a floating glass tooltip card. Clicking zooms the camera in and opens the existing detail panel on the right.
The aesthetic is directly derived from the Pinterest examples: specifically the Artem Kazakov grid-of-glass-cubes structure with the 3D Glassmorphism Growth Chart colour language and the NAVER green glass slabs depth treatment.

2. Scene Architecture
Camera

PerspectiveCamera, FOV 45
Initial position: isometric-ish — (0, 120, 80), looking at grid centre (0, 0, 0)
OrbitControls with limited polar angle (30°–75°) and azimuth locked to ±60° to keep it readable
Smooth animated transitions when a cell is selected (GSAP or lerp per frame)

Lighting

AmbientLight — warm cream #f5f0e8, intensity 0.6 (matches site's parchment background)
DirectionalLight — #ffffff, intensity 1.2, from top-right (50, 100, 50)
PointLight — neon green #00ff88, intensity 40, decay 2, placed at (0, 20, 0) — gives the inner glow to active cells
PointLight — blue #4488ff, intensity 20, decay 2, placed at (-50, 30, -30) — cool rim fill

Renderer

WebGLRenderer with antialias: true, alpha: true
renderer.shadowMap.enabled = true, PCFSoftShadowMap
renderer.toneMapping = ACESFilmicToneMapping, exposure 1.1
Background: transparent (CSS background of the container is the site's #f0ebe0 parchment)


3. Grid Geometry
The core scene is a 53 × 36 grid (weeks × years), but only the 123 occupied cells have risen prisms. Empty cells exist as flat ghost squares for spatial orientation.
Base plane
PlaneGeometry(53 * cellSize, 36 * cellSize)
MeshStandardMaterial({ color: #d8d0c0, roughness: 0.8, metalness: 0.0 })
Rotate -90° on X to lie flat. Cast subtle grid lines as GridHelper with colour #c0b898, divisions matching cell count.
Empty cells (the ~1,677 unfilled week-slots)
BoxGeometry(cellSize * 0.85, 0.5, cellSize * 0.85)   // flat, almost flush with ground
MeshPhysicalMaterial({
  color: #d4cfc6,
  transparent: true,
  opacity: 0.3,
  roughness: 0.05,
  metalness: 0.1,
  transmission: 0.2
})
These form the "ghost grid" — the dashed-border cells from the 2D view translated to 3D.
Filled entry cells — the glass prisms
BoxGeometry(cellSize * 0.88, entry.era * heightUnit, cellSize * 0.88)
// heightUnit = 3.0, so Era 10 = 30 units tall, Era 1 = 3 units tall
MeshPhysicalMaterial({
  color: TAG_COLORS[dominantTag],     // see colour map below
  transparent: true,
  opacity: 0.45,
  roughness: 0.05,
  metalness: 0.15,
  transmission: 0.7,
  thickness: 1.5,                     // IOR refraction thickness
  ior: 1.5,
  envMapIntensity: 1.2
})
Each prism is centred on its week-column + year-row coordinate. Its Y position = (era * heightUnit) / 2 so it sits on the base plane.
Inner glow core (the neon effect from the SaaSAssetLab pin)
Inside each entry prism, add a smaller box at 60% scale:
BoxGeometry(cellSize * 0.5, entry.era * heightUnit * 0.8, cellSize * 0.5)
MeshStandardMaterial({
  color: TAG_COLORS[dominantTag],
  emissive: TAG_COLORS[dominantTag],
  emissiveIntensity: 0.6,
  transparent: true,
  opacity: 0.15
})
This creates the soft inner luminescence visible in the Kaspersky/NAVER examples.

6. Interaction
Hover

Raycast on mousemove against all entry prism meshes
On intersection: scale prism up to 1.05 (lerp), increase emissiveIntensity to 1.2, show floating label (HTML overlay position: absolute driven by Vector3.project())
Floating label shows: title, year-week, tag pills, Era dot

Click / Select

Camera smoothly animates to look at the selected prism from slightly above and in front
The existing right-hand detail panel populates with the entry data (same as clicking in the 2D view — reuse the existing showEntry() function)
Selected prism gains a thin outer wireframe ring: EdgesGeometry + LineBasicMaterial({ color: #ffffff, linewidth: 2 }) and a subtle PointLight child placed at the prism's top centre

Zoom-to-year

Clicking a year label on the left axis animates the camera to frame that year's row in full width

Mode toggle

A single "3D / 2D" button in the header toggles between the Three.js canvas and the existing flat grid
The Three.js renderer canvas sits as a sibling to the existing grid container, z-index managed by CSS


7. Performance

123 entry prisms: fine as individual meshes
~1,677 ghost cells: merge into one InstancedMesh with a single MeshPhysicalMaterial — this is critical for performance
The PMREMGenerator environment map is generated once from a simple RoomEnvironment for the glass material reflections
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)) — cap at 2x
requestAnimationFrame loop runs only when camera is moving or a hover/animation is active; otherwise paused with renderer.setAnimationLoop(null)


8. File Structure for Claude Code
src/
  three/
    SceneManager.js        ← renderer, camera, controls, resize handler
    GridBuilder.js         ← builds the 53×36 base grid + InstancedMesh ghost cells
    EntryPrisms.js         ← creates/updates glass prisms from ledger data
    LabelSprites.js        ← year + week axis label sprites
    Interactions.js        ← raycaster, hover, click, camera animation
    TagColors.js           ← the colour map constant
    materials/
      GlassMaterial.js     ← reusable MeshPhysicalMaterial factory
      GhostMaterial.js     ← reusable ghost cell material
  SpatialView.js           ← top-level component: mounts canvas, wires data, exposes toggle()
Entry into the existing site: In the main index.html / JS entry point, after the existing grid initialises, call:
jsimport { SpatialView } from './three/SpatialView.js'
const spatial = new SpatialView(ledgerData, containerEl)
document.querySelector('#toggle-3d').addEventListener('click', () => spatial.toggle())
ledgerData is the same array the existing 2D grid already has access to — no new data pipeline needed.
