Design System

A single source of truth rebuilt from scratch on the IBM Carbon foundation. One token layer, one type family, zero legacy overrides. Every surface of the archive draws from the primitives on this page.

01 — Color tokens

Semantic palette

Tokens are named by role, never by value. The same token name resolves to different hexes across themes — components never reference raw color.
